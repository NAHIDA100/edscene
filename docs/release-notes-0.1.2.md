# edscene 0.1.2 发行说明

集成工业播报终端 —— 《明日方舟：终末地》基地播报风格的**同人二创**系统事件语音提醒工具。
登录、解锁、锁屏、屏保恢复、电源接入/断开、低电量这些时刻，它会用游戏里那套合成语音念一句。
Windows 与 Linux 双平台，界面仿游戏设置页。

> 非官方、非商业，与鹰角网络无隶属、无授权关系。**源码仓库不含任何游戏素材**；
> 只有本目录的安装程序附件里带着那 8 条语音与一张背景图，仅供个人学习使用。

## 这一版修了什么

全部围绕一件事：**装不上自启的时候，以前没人知道为什么。**

- **开机自启的注册结果一律落盘**：`%PROGRAMDATA%\edscene\service-install.log`，一行一次，
  带时间、成败、执行这条命令的是哪个 exe，以及完整失败原因。这一步只有安装向导和 UAC
  提权出来的子进程会做，而它们两个都没有能看见的控制台 —— 以前失败只剩一句「退出码 1」。
- **向导弹错不再只报退出码**：给出上面那份日志的完整路径，并问要不要立刻用记事本打开。
  勾选"开机自启"但按你的选择关闭时失败，也同样处理。
- **「服务启动后立刻退出了」会把服务自己的遗言一起带出来**：会话 0 里的崩溃没有任何弹窗，
  现在这条错误会附上 `state\events.ndjson` 里服务写下的最后一条记录。
- **点「以管理员身份开启」之后窗口会自己确认结果**：每秒查一次服务，装上就变绿并提示
  已注册；45 秒内没装上就把日志路径写在提示条里 —— 不再是"点了什么也没发生"。
- **服务镜像固定指向你刚执行命令的那个 exe**（在 `target\` 里跑的除外）。以前会保留服务
  原本指向的路径，于是"曾经从下载里解压跑过一次"的机器装完新版，开机自启启动的还是那个
  旧副本，表现就是装了新版照样没效果。

## 装完不自启 / 没声音，三步定位

1. `C:\ProgramData\edscene\service-install.log` —— 最后一次的失败原因就在最后一行。
2. `C:\ProgramData\edscene\state\events.ndjson` —— 有没有 `service-exit`，它的 `err` 是什么。
3. `sc.exe query edscene-broadcast` 的状态，以及 `Get-Item 'C:\Program Files\edscene\edscene.exe'`
   的大小（本版本应为 18 889 573 B，确认新版真的覆盖上了）。

把这三样发出来就能定位，不需要重装。

## 安装（Windows）

双击 `setup.exe` → 一次 UAC → 中文向导：欢迎 → **版权与素材说明** → 安装位置（默认
`C:\Program Files\edscene`）→ 附加任务 → 确认 → 进度 → 完成。

- **开机自启默认已勾**：注册成系统服务 `edscene-broadcast`，登录界面出现之前就已加载，
  所以输完密码进桌面那一声不会漏；崩溃后 5s / 30s / 60s 自动重启。
- 语音就在安装目录的 `sounds\` 里，程序自动采用，不需要再手工指文件夹。
- 无人值守：`.\edscene-setup-0.1.2-windows-x64.exe /VERYSILENT /NORESTART /TASKS=autostart`。
- 卸载走 Windows「设置 → 应用」；配置与替换过的音频不会被删。

Linux：`.deb` / `.tar.gz` 由 CI 随本标签产出；装好后 `edscene --sounds <你的素材目录>`，
在设置里打开自启（写 systemd 用户单元，不需要 root）。Linux 的自启是你自己账号下的单元，
成功与否 `systemctl --user status edscene` 直接可见，不需要那套日志。

## 用法速记

8 个事件：开机进入桌面、解锁返回桌面、锁屏、屏保恢复、低电量模式、电池电量低于5%、
断开电源、电源恢复接入。出厂启用其中 5 个。

```powershell
cmd /c "edscene --selftest"          # 8 个事件各自找到哪个文件
cmd /c "edscene --selftest unlock"   # 试听一条
cmd /c "edscene --simulate unlock,ac_lost"
cmd /c "edscene --watch"             # 只看系统信号判定，不出声
cmd /c "edscene --config-path"       # 配置与日志在哪
```

> 在 PowerShell 里**不要**直接 `edscene --selftest`：程序按 GUI 子系统编译（所以双击不会
> 附带黑色控制台），PowerShell 对 GUI 程序不等待也不接管道，输出会像被吞掉。用上面的
> `cmd /c`，或 `Start-Process -Wait -RedirectStandardOutput`。

素材文件名就是事件名，**不看扩展名**（随包那 8 个后缀写着 `.mp3`，实际是 AAC-in-MP4，
程序按文件头判断）。换成 `锁屏.wav`、`锁屏.flac` 都不用改设置；替换过的原件会被保留，
「恢复默认」随时退回。

## 已知限制

- 「低电量模式」从"离线 + 电量阈值"派生，不是系统省电模式的真实状态：手动开 Windows
  省电模式不会播报。
- 「屏保恢复」是启发式判据，因此出厂关闭。
- Linux 登录界面（greeter）阶段能否出声取决于发行版的音频套接字策略，不承诺通用。
- 无边框模式下没有系统级贴边吸附与双击最大化；需要那套就用默认的系统标题栏。
- 本版的自启日志与提权轮询，在作者机器上实测的是**未提权失败**那条路径（日志确实落了
  盘、时间戳与中文正常、原因完整）；**注册成功**那条要等一次真实的 UAC 确认才能走完，
  装的时候如果向导没报错、`sc.exe query edscene-broadcast` 是 RUNNING，就说明也通了。
- 别人机器上那次「退出码 1」的确切原因仍待那份 `service-install.log` 回来 —— 这一版的
  全部意义就是让它可见。
- CI 的 `windows-msvc` 与 `linux` 两条测试作业从建仓起就一直红（Linux 那条已定位成缺
  `-dev` 头文件并修了；msvc 那条还没日志）。所以下面说的"CI 产出 Linux 包"目前还不可靠，
  需要 `.deb` 的先找作者拿本地构建。
