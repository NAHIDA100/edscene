# edscene 0.1.1

集成工业播报终端 —— 《明日方舟：终末地》基地播报风格的**同人二创**系统事件语音提醒工具。
登录、解锁、锁屏、屏保恢复、电源接入/断开、低电量这些时刻，它会用游戏里那套合成语音念一句。
Windows 与 Linux 双平台，界面仿游戏设置页。

> 非官方、非商业，与鹰角网络无隶属、无授权关系。**仓库里不含任何游戏素材**；
> 只有下面的安装程序附件里带着那 8 条语音与一张背景图，仅供个人学习使用。

## 安装（Windows）

双击 `setup.exe` → 一次 UAC → 中文向导：欢迎 → **版权与素材说明** → 安装位置（默认
`C:\Program Files\edscene`）→ 附加任务 → 确认 → 进度 → 完成。

- **开机自启默认已勾**：注册成系统服务，登录界面出现之前就已加载，所以你输完密码进
  桌面那一声不会漏。
- 语音在安装目录的 `sounds\` 里，程序自动采用，不需要你手工指文件夹；想换成自己的
  素材，设置 → 播报事件 → 选目录即可。
- 卸载走 Windows「设置 → 应用」；你的配置与替换过的音频不会被删。

Linux：`sudo dpkg -i edscene_*_amd64.deb && sudo apt -f install`，然后
`edscene --sounds <你的素材目录>`，在设置里打开自启（写 systemd 用户单元，不需要 root）。

## 这个版本里有什么

- **修好"打开设置时旁边跟一个黑色命令行窗口，关掉它程序就没了"**：程序原先按控制台子系统
  编译，双击或从安装向导启动都会附带一个控制台；现在按 GUI 子系统编译，命令行用法照样有输出。
- **修好"重启之后托盘图标不见了"**：托盘原先在 Explorer 之前启动时注册失败且不重试，
  进程活着但图标永远不出现。现在失败每 2 秒重试，并监听 `TaskbarCreated`，Explorer
  起来或重启后自动补上；结果写进日志（`tray-ready` / `tray-wait`）。
- **安装程序换成中文图形向导**，不再是要你在黑窗口里手打 `yes` 的脚本。
- **素材目录跟着安装目录走**：配置为空或指向不存在的目录时，自动采用安装目录里的
  `sounds\`，不再钉死某个绝对路径。
- **开机播报只由「开机进入桌面」一个开关决定**：Windows 建桌面时会连着发
  Logon→Lock→Unlock，这段动画以前被当成真实的锁屏/解锁，于是关掉开机播报仍然响一声。
- 外观即时生效：强调色、动效、装饰、圆角、边框改完立刻重画；开关不再触发整盘扫描。
- 无边框模式下窗口可以自己拖动（系统接管那套会在界面回调里吃掉鼠标抬起，导致拖完点不动）。
- 设置窗口单实例：再开一个会唤回已有的那个，托盘不会越开越多。
- Linux 侧修到能在真机（Ubuntu 26.04）上编译并运行：D-Bus 事件源、ALSA 出声、
  systemd 用户单元自启都实测过。

## 用法速记

8 个事件：开机进入桌面、解锁返回桌面、锁屏、屏保恢复、低电量模式、电池电量低于5%、
断开电源、电源恢复接入。出厂启用其中 5 个。

```powershell
edscene --selftest              # 8 个事件各自找到哪个文件
edscene --selftest unlock       # 试听一条
edscene --simulate unlock,ac_lost
edscene --watch                 # 只看系统信号判定，不出声
edscene --config-path           # 配置与日志在哪
```

素材文件名就是事件名，**不看扩展名**（随包那 8 个后缀写着 `.mp3`，实际是 AAC-in-MP4，
程序按文件头判断）。换成 `锁屏.wav`、`锁屏.flac` 都不用改设置；替换过的原件会被保留，
「恢复默认」随时退回。

## 已知限制

- 「低电量模式」是从"离线 + 电量阈值"派生的，不是系统省电模式的真实状态：手动开
  Windows 省电模式不会播报。
- 「屏保恢复」是启发式判据，因此出厂关闭。
- Linux 的登录界面（greeter）阶段能否出声取决于发行版的音频套接字策略，不承诺通用。
- 无边框模式下没有系统级的贴边吸附与双击最大化；需要那套就用默认的系统标题栏。
